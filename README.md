# Simple Interest Calculator

A simple Bash script that calculates simple interest based on
user-provided principal, annual interest rate, and time period.

## Description

This project was developed as the final project for the IBM Introduction to Git and GitHub course taken in Coursera

The Simple Interest Calculator demonstrates basic Bash scripting
and open-source collaboration using Git and GitHub.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal: Initial amount of money
- Rate: Annual interest rate (percentage)
- Time: Duration in years

## How to Run

1. Clone the repository:

   git clone [https://github.com/bellamarbellaa/github-final-project]

2. Navigate to the project directory:

   cd github-final-project

3. Run the script:

   bash simple-interest.sh

4. Enter the requested values.

## Example

Principal: 1000
Rate: 5
Time: 2

Simple Interest: 100

# Code of Conduct

## Our Pledge

As contributors and maintainers of the Simple Interest Calculator
project, we are committed to creating a welcoming, respectful,
and inclusive environment for everyone.

We welcome individuals of all backgrounds, identities, abilities,
and experience levels. Our goal is to encourage collaboration,
learning, and meaningful contributions to this open-source project.

## Our Standards

We expect all community members to demonstrate professionalism,
respect, and kindness.

Examples of positive behavior include:

- Treating others with respect and consideration.
- Welcoming new contributors and helping them learn.
- Providing constructive feedback on code and documentation.
- Respecting different opinions, perspectives, and experiences.
- Taking responsibility for mistakes and learning from them.
- Prioritizing the overall success of the project.

Unacceptable behavior includes:

- Harassment, discrimination, or intimidation.
- Offensive, insulting, or derogatory comments.
- Personal attacks or deliberately disruptive behavior.
- Sharing another person's private information without permission.
- Any behavior that creates an unsafe or unwelcoming environment.

## Enforcement Responsibilities

Project maintainers are responsible for communicating and
enforcing the standards outlined in this Code of Conduct.

Maintainers may review, edit, reject, or remove comments,
commits, pull requests, issues, and other contributions that
violate these guidelines.

Enforcement decisions will be made fairly, consistently,
and with consideration for the circumstances involved.

## Scope

This Code of Conduct applies to all project-related spaces,
including:

- GitHub repositories
- GitHub Issues
- Pull requests and code reviews
- Project discussions
- Other communication channels associated with the project

It also applies when contributors officially represent
the project in public or community spaces.

## Enforcement Guidelines

Project maintainers will follow these guidelines when
addressing violations of the Code of Conduct.

### 1. Correction

**Community Impact:**
Minor inappropriate behavior or unprofessional communication.

**Consequence:**
A private warning explaining the issue and requesting
appropriate changes in behavior.

### 2. Warning

**Community Impact:**
Repeated inappropriate behavior or a more serious violation
of community standards.

**Consequence:**
A formal warning outlining the violation and potential
consequences of further misconduct.

### 3. Temporary Ban

**Community Impact:**
Serious or repeated violations that negatively affect
the community.

**Consequence:**
Temporary restrictions on participation in project discussions,
issues, pull requests, or other community interactions.

### 4. Permanent Ban

**Community Impact:**
Severe harassment, threats, or continued violations despite
previous warnings.

**Consequence:**
Permanent removal from participation in project-related
community spaces, where technically and administratively possible.
